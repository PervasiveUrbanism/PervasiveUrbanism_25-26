# Skills Module 1 — Cartographies of Affect

## OUTLINE

This module introduces desktop-based data-mining techniques for urban analysis. Students will learn how to collect, process, and interpret digital traces from public datasets and online platforms, building a Python foundation for handling and structuring complex datasets. Through working with APIs such as Flickr and Google, you will extract geotagged images, metadata, and text, then transform these into meaningful spatial visualisations. The module concludes with mapping workflows in Rhino and Grasshopper and producing clear diagrammatic and sentiment-based graphics.

## LEARNING CONTENT

* Understanding how to collect, process, and structure urban data from public sources and online platforms.
* Building core Python skills for working with APIs, JSON datasets, and sentiment-analysis workflows.
* Extracting geotagged images, metadata, and textual content from platforms such as Flickr and Google.
* Visualising datasets through maps, diagrams, and sentiment-based spatial representations using Python and Rhino/Grasshopper.

## ASSIGNMENT

Choose a neighbourhood in a city of your choice and develop a *sentiment-based spatial map* using data collected from a platform such as Flickr or Google. Use Python to extract geotagged images, metadata, and text (titles, tags, comments), run a sentiment analysis on the dataset, and visualise the results in Grasshopper. The final output should be refined in Illustrator and accompanied by a short explanation of your workflow, data choices, and findings.



# Skills Module 2 — Prosthetic Clouds

## OUTLINE

This module explores how to create a wearable device that mediates between the body and the city. Using Arduino, you will build sensor-based tools capable of logging environmental and physiological data. GPS will allow you to locate events in space and time, while onboard storage or wireless communication will let you save or stream information to a computer. You will learn how to visualise the collected data in Rhino, Grasshopper, and vvvv to generate spatial and temporal readings of urban experience.

## LEARNING CONTENT

* Introduction to Arduino: hardware basics, the structure of the UNO board, and foundational programming skills.
* Understanding common sensors such as GPS, GSR (skin response), and air-quality sensors, and learning how to collect and record their data.
* Building a data-logging device that captures sensor readings, timestamps them, and saves data to an SD card.
* Streaming sensor data to a computer in real time using vvvv.
* Visualising sensor output spatially and temporally in Rhino and Grasshopper.

## ASSIGNMENT

Produce a *technical report* documenting the wearable device you developed in Term 1. Explain how the system works, including circuit diagrams, code, sensor logic, and data examples. Present your results using maps, timelines, and diagrams generated in Grasshopper or vvvv.
If your group project does not allow each student to clearly demonstrate individual work, you may alternatively design and document a *simplified Arduino-based data logger* that records a walk. This version should follow the tutorial code but include small modifications of your own, and does not require a design component.
